一个为 Minecraft Fabric 1.21.1 添加电影视角功能的模组。

## 功能

- 🎬 一键切换电影视角模式
- ⬛ 上下黑边遮幅（默认 10%）
- 🖐️ 隐藏手中物品
- 📦 隐藏 HUD 和物品栏
- 🎥 平滑视角切换

## 使用方法

1. 安装 Fabric Loader 和 Fabric API
2. 将模组放入 `mods` 文件夹
3. 游戏中按 **F6** 开启/关闭电影视角

## 自定义

可在配置文件中调整黑边高度和快捷键。
